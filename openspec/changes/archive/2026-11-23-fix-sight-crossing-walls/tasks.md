- [x] 1.1 Add `splitSegments(segments)` to `packages/shared/src/sight.ts` (or `sightSegments.ts`, re-exported from `src/index.ts`). Implement design Decision 3 in order: drop zero-length segments; find candidate pairs with a bounding-box sweep; classify each pair as crossing, on the same line, or parallel on separate lines, using the sine-of-angle test; record each crossing point once and use it for both segments; cut overlapping walls at each other's exact endpoints; merge cuts within EPS; drop slivers; dedupe exact matches in either direction, preferring the wall source. Verify with `npm test --workspace=@vtt/shared -- sightSegments`.
