# Session Zero User Guide

Session Zero is a virtual tabletop for running tactical tabletop RPG encounters in the
browser. A Game Master (GM) prepares a battle map and runs the fight. Players join from a
link, with no account, and control their own characters.

The live site is <https://sessionzero.codes>. The app is available in English and
Traditional Chinese (**Settings → Language**).

## Words used in this guide

| Term | Meaning |
| --- | --- |
| **GM** | Game Master. Runs the room, prepares maps, controls monsters and rules on attacks. |
| **Player** | Anyone else at the table. Controls the tokens the GM gives them. |
| **Room** | One game table. It keeps its map, tokens and history between sessions. |
| **Token** | A character or creature on the board. |
| **Scene** | One prepared board in a room. A room can hold several and switch between them. |
| **Area** | A spell or effect shape on the board: circle, cone, line or square. |
| **Difficult terrain** | Squares that cost double movement. |
| **Blocked terrain** | Squares no token can enter. |
| **Ruling** | The GM's Hit or Miss decision on an attack roll. |
