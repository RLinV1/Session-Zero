# Cairnkeepers art: credits

All of Cairnkeepers' art is drawn in code for this project. Nothing is traced, sampled or
generated by an image model.

| Art | Made by | How |
|---|---|---|
| Maps (`maps/*.webp`, GM keys) | `scripts/cairnkeepers/render-maps.mjs` + `draw-map.mjs` | A canvas in headless Chromium. Each map is an ASCII layout (`layouts.mjs`): the ground is coloured per pixel through a seeded noise warp, rock, ice and crevasses are cut on the grid with a smooth displacement, and contour lines come from a noise height field. |
| Walls, ice, terrain, fog (`maps/*.board.json`, `.dd2vtt`) | `render-maps.mjs` | Built from the same layout as the art, so they line up with it. |
| Tokens (`tokens/*.webp`, `tokens/src/*.svg`) | `scripts/cairnkeepers/render-tokens.mjs` | Hand-written SVG, rendered in Chromium and converted with sharp. |
| Character sheet, rulebook and adventure PDFs | `scripts/cairnkeepers/render-sheets.mjs` | HTML printed by Chromium. |

**Fonts** (Google Fonts, loaded by the sheet and the PDFs): *Special Elite* (Apache License 2.0),
*Kalam* and *Crimson Pro* (SIL Open Font License 1.1).

To change anything, change the source and re-run the script; see the game's README.
